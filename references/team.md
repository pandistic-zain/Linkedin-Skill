# Team Roster (employee advocacy)

Who would actually be posting, and the constraints they post under.
`linkedin-employee-advocacy` reads this to produce the 14-day launch plan,
cadence targets and KPI spec. It is a consult, not an invite: nothing here
sends anyone a request, and no post goes out from it.

> **This file is in the repository, so git can carry it.** It holds names,
> roles and handles of real colleagues. Keep the filled copy outside the repo
> and paste it in when you run the skill: the shipped template is empty,
> `filled: no`, and `scripts/check_no_secrets.py` fails any tracked copy
> marked `filled: yes` before it can be pushed. What you add is yours to
> protect.

The skill only reads this when `filled: yes` below. Empty means "no team
configured", and the scheduled run reports that instead of inventing a roster.
