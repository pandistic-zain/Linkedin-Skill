# LinkedIn Profile Snapshot

Your profile as it is right now, pasted once. `linkedin-profile-optimizer`
reads this instead of asking you for nine screenshots: it scores every
section, ranks the fixes, and hands you Before -> After rewrites. Refresh it
whenever you have changed something (a new role, a new Featured item) - it is
a snapshot, not a live copy.

> **This file is in the repository, so git can carry it.** A filled snapshot
> names your employers, clients and metrics. Keep the filled copy outside the
> repo and paste it in when you run the skill: the shipped template is empty,
> `filled: no`, and `scripts/check_no_secrets.py` fails any tracked copy
> marked `filled: yes` before it can be pushed. What you add is yours to
> protect.

The skill only reads this when `filled: yes` below. An empty template is
ignored, and the skill reports the run as "not configured" instead of
guessing.
