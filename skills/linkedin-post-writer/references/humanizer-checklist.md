# Post and image review

- [ ] One useful observation, clear to a freelance/full-stack audience.
- [ ] Each factual claim traces to an original source or permitted user evidence.
- [ ] Dates, counts, and image labels agree with the sources.
- [ ] No invented first-person client story, result, or sensory detail.
- [ ] No drafting notes, output labels, character counts, forced P.S., or generic CTA.
- [ ] Natural paragraphs; no artificial rhythm or required formula.
- [ ] Sources and asset credits appear in the approved reader-facing package.
- [ ] The actual image was inspected and remains readable on a small screen.
- [ ] Source page, reuse terms, and creator credit are verified for sourced imagery.
- [ ] An original explanation is used when asset reuse is uncertain.
- [ ] Text and visual make the same supported claim.
- [ ] Only the exact reviewed revision can publish.

Do not use an AI-detector score as proof of human authorship. No detail quotas.
Block missing evidence or visual review; offer one bounded repair, then hold.
